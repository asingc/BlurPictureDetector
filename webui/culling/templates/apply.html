Quick re-uses the sharpness scores already measured, then re-checks jersey colours and re-polls the team colour against the new cut-line — fast, but it can't revisit photos where no usable face was detected. Deep additionally re-detects people and re-measures sharpness from the original photos, so it also fixes albums where detection itself was off — much slower. Both keep your star ratings and face tagging.

Team Jersey Colour

By default this album's team colour is auto-detected from the photos. Pin it here if detection picked the wrong colour — every photo is re-checked against the new colour, star ratings for any photo that changes side of the keep line are reset to their baseline, and the previews/thumbnails for those photos are redrawn. Face tagging is untouched — face recognition doesn't depend on jersey colour.

Import More Images

Add photos from another folder into this album. Files already imported (matched by source path) are automatically skipped — importing the same folder twice is harmless. Newly imported photos go through the full pipeline (blur detection, face recognition, LLM culling) using this album's original settings.

Re-run Face Detection

Re-clusters faces from scratch using this album's already-detected photos (no re-import, no re-detecting blur). Existing tagged players and deletions from the Faces page are preserved; untagged/pending clusters may be renumbered or grouped differently.

Export to Folder

Copies every photo at or above the selected star rating to a destination folder of your choice. If face tagging is enabled below, also generates a players.csv file listing which players appear in each photo.
